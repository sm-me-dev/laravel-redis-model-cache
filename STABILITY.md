# Stability Commitment

`SMDev\RedisModelCache` is the committed public PHP namespace for this
package through v4.

Future breaking namespace changes require a major-version release and a
documented migration path. Minor and patch releases will not rename the public
namespace, provider, contracts, traits, jobs, events, or documented facades.

The Packagist package name is also stable:

```text
sm-me/laravel-redis-model-cache
```

Migration tooling or aliases for older releases do not change this commitment.
